# 그려봄 변경 내역

1.0.0 부터 정식 버전이에요. 버전마다 설치용 배포 묶음(`geuryeobom-v<버전>.zip`)은
깃허브 [Releases](https://github.com/hatility/Gryeobom/releases) 에서 받을 수 있고, 푼 폴더에서 `docker compose up -d --build` 로 실행해요.

버전은 `주.부.수` 세 자리로 매겨요.

- **예전 버전과 함께 쓸 수 없게 크게 바뀔 때** → 첫 숫자 (1.x.x → 2.0.0) — 올리기 전에 꼭 백업하고 안내를 읽어 주세요
- **기능 추가** → 가운데 숫자 (1.0.0 → 1.1.0)
- **버그 수정 · 작은 손질** → 마지막 숫자 (1.0.0 → 1.0.1)

`0.x.x` 는 정식 버전 전 미리보기 기록이에요.

---

## [1.1.0] - 2026-11-05

### 추가
- **모바일 · 태블릿 전용 화면 `/m`**: 휴대폰 · 태블릿으로 들어오면 자동으로 `/m` 으로 열려요. 기능 · 저장은 PC판과 같고, 화면 틀이 앱처럼 바뀌어요.
  - **아래 탭바** 처음 · 기록 · 그리기 · 함께 · 나 — 가운데 ‘그리기’는 떠 있는 동그란 버튼
  - **위 앱 바** 뒤로 가기 버튼, 내리면 화면 제목이 작게 떠올라요
  - **모바일 첫 화면** 인사 · 새 그래프 그리기 · 이어 그리기 · 오늘의 질문 · 내 그래프를 옆으로 넘겨 보기 · 모임 주제
  - **‘나’ 화면** 계정 · 화면 밝기 · 글자 크기 · 약관 · 오픈소스 · PC 화면으로 보기 · 로그아웃을 한곳에
  - **아래에서 올라오는 시트** 공유 · 신고 · 저장 같은 팝업
  - **기록 목록** 작은 그래프를 왼쪽에 둔 줄 모양
  - 누르면 살짝 눌리는 느낌, 화면이 바뀔 때 부드럽게 떠오름, 손가락 크기 버튼(44px), 입력할 때 확대되지 않는 입력칸, 노치 · 홈 막대 자리 비움
  - **태블릿** 아래 탭바 대신 왼쪽 세로 메뉴, 기록은 2열 (가로로 넓으면 3열)
- **화면 바꾸기**: ‘나 → PC 화면으로 보기’ · PC 바닥글 ‘모바일 화면으로 보기’. 고른 화면은 그 기기에서 기억해요.
- 초대 · 공유 링크는 그대로 쓰면 되고, 여는 기기에 맞는 화면으로 열려요. 관리자 화면은 PC판으로 열려요.

### 고침
- 모임 글 목록의 작은 선을 순간이 놓인 구간에 맞춰 그려, 카드마다 같은 폭으로 보여요. ‘모임 이름 · 소개 고치기’ 버튼 여백을 맞췄어요.
- 공유하기의 ‘아직 들어간 모임이 없어요’ 안내가 링크 앞뒤로 끊겨 보이던 것.
- 좁은 폰(360px)에서 그래프 결과 화면의 버튼 줄이 화면 밖으로 넘치던 것.
- 폰에서 그래프 그리기 머리의 제목이 ‘그만 그리기’ · 저장 표시에 밀려 두 줄로 꺾이던 것 — 버튼은 제목 아래로.
- 위 ‘로그인’을 누르면 로그인한 뒤 보던 화면으로 돌아와요 (초대 · 모임 · 공유 화면에서).
- 로그인하지 않은 ‘나’ 화면에 로그인 버튼이 두 개 보이던 것.
- 폰을 눕혔을 때 왼쪽 세로 메뉴가 화면 높이를 넘던 것 — 낮은 화면은 아래 탭바를 가운데로 모아 써요.

## [1.0.0] - 2026-11-04

첫 정식 버전이에요. 0.x 동안 만든 기능(그래프 · 회고 · 모임 · 공유 링크 · 오늘의 한 줄 · 연말 돌아보기 · 관리자 화면 · 백업 / 복원)을 모두 담았어요.

### 추가
- **진짜 접속 IP**: 리버스 프록시 · 로드밸런서 · Cloudflare 같은 앞단 프록시 뒤에서도 관리자 접속 기록 · 로그인 시도 제한에 원래 접속 IP 가 남아요. `.env` 의 `TRUSTED_PROXIES` 에 프록시 대역을 적어요 (예: `172.16.0.0/12`). 적은 곳에서 온 `X-Forwarded-For` 만 믿어요.
- **신고 기록 지우기**: 관리자 신고함에서 ‘기록 지우기’ — 무엇을 지우는지 보여 주는 팝업에서 까닭을 고르거나(시험 · 중복 · 잘못 들어온 신고 · 이미 처리한 일) 직접 적어야 지워지고, ‘지운 신고’에서 1년 동안 볼 수 있어요.
- **오늘의 한 줄은 로그인한 계정만**: 로그인하지 않으면 질문만 보이고 ‘로그인하고 남기기’로 안내해요. 이 기기(브라우저)에는 더 이상 한 줄을 저장하지 않아요.
- **내린 글 바로 다시 나누기**: 모임장 · 운영자가 내린 그래프는 그린 사람이 고치면 같은 모임에 바로 다시 올라가요 (직접 골라 나눈 글은 고른 순간 그대로). 스스로 내린 글은 그대로 내려가 있어요.

### 바뀜
- 관리자 ‘사람 자세히’: 프로필 머리(가입 · 마지막 방문 · 기기 · id), 숫자 띠 6칸, 모임 · 나눈 그래프 · 공유 링크 · 한 줄 · 기록을 구역 카드로.
- 관리자 화면 너비를 위 메뉴와 맞췄어요 (왼쪽 끝 어긋남).
- 관리자 가로 간격: 메뉴와 본문 사이를 넓히고, ‘한눈에’ 숫자 카드를 3칸 × 2줄로 (글자가 두 줄로 꺾이지 않게).
- 바닥글 · 오픈소스 · 약관 화면에 남아 있던 ‘미리보기’ 문구를 뺐어요. 약관 위 안내는 운영 기관 · 문의처를 정하지 않았을 때만 보여요.
- 4단계 ‘지금의 나에게’ 순간 목록: 시점 칸 너비를 맞추고, 한 줄씩 계단처럼 떠오르지 않고 한 번에 부드럽게.
- 저작권자에 ‘하남시청소년수련관 Team HATILITY’ 를 더했어요 (NOTICE · 만든 사람 화면). 개인정보 처리방침의 권리 침해 구제 기관 이름을 ‘대검찰청’ → ‘공소청’ 으로 고쳤어요.
- 이용약관 · 개인정보 처리방침 (2026년 11월 4일 시행): 1.0 의 모든 기능을 다시 정리했어요 — 서비스 내용(그리기 · 남기기 · 오늘의 질문 · 모임 · 보기), 로그인해야 쓰는 기능, 탈퇴할 때 함께 지워지는 것(한 줄 · 링크 · 응원 · 모임장이면 모임), 기기 안에서 만들어지는 이미지 · PDF, 자동 백업과 웹 복원, 내린 글 다시 나누기, 신고 기록 지우기와 보관, 프록시를 거친 접속 IP.
- 오픈소스: 개발 도구 `vitest` 5.1.0 · `@vitejs/plugin-react` 6.2.1 로 올리고 목록 · 원문을 다시 모았어요 (145개, 원문 확인 완료). Docker 이미지 속 패키지는 바뀐 것이 없어요.

### 고침
- 신고 내용이 아주 길거나 띄어쓰기가 없으면 카드가 화면 밖으로 늘어나던 것 (모든 카드에서 긴 글이 줄을 바꿔요).
- ‘그때 오늘’: 31일 · 2월 29일처럼 그 달에 없는 날이면 엉뚱한 날짜의 한 줄을 보여 주던 것.
- 화면을 열어 둔 채 밤 9시 · 10시를 넘기면 밝기 · 조용한 시간이 바뀌지 않던 것.
- 연말 돌아보기가 최근 400개의 한 줄만 읽던 것 → 1200개.

## [0.19.0] - 2026-11-03

### 추가
- **마음 색 일기**: 오늘의 한 줄에 오늘의 색(햇살 · 설렘 · 뜨거움 · 잔잔 · 맑음 · 몽글 · 흐림 · 깊음)을 골라요. 나의 한 줄 달력이 그 색으로 물들어요.
- **그때 오늘**: 첫 화면에 1년 전(최대 5년) → 한 달 전 → 일주일 전 같은 날 남긴 한 줄을 살짝 띄워요.
- **연말 돌아보기** (`/review/연도`): 한 줄을 남긴 날 · 새로 그린 선 · 이 해의 순간, 하루 한 칸 마음 색 지도, 가장 많이 고른 색, 가장 환했던 / 무거웠던 순간, 처음과 최근의 한 줄. ‘한 장으로 저장하기’로 4:5 이미지. 12월 · 1월에는 기록 모아보기 위에 안내가 떠요.
- **조용한 시간**: 밤 10시 ~ 새벽 5시에는 더 어둡고 잔잔한 화면(움직임 멈춤), 질문도 잠들기 전에 어울리는 16개로 바뀌어요. ‘보기’에서 끌 수 있고, ‘밝게’로 고정한 사람은 그대로예요.

### 고침 · 다듬음
- 모바일 결과 화면: 버튼 5개 중 ‘공유하기’가 반 칸으로 남던 것 → 맨 위 한 줄로.
- 그래프 왼쪽 아래 계절 이름(겨울)이 ‘↓ 무거웠던 마음’과 겹치던 것.
- 모바일 ‘함께 나누기’: 원칙 카드 4개가 첫 화면을 다 차지하던 것 → 2×2 작은 카드.
- 모바일 관리자: 메뉴 아래 스크롤 막대 숨김, 숫자 카드 촘촘하게. 모바일 화면 위 여백 조금 더.
- 달력에서 색을 고른 날은 점 대신 색으로만.

## [0.18.0] - 2026-11-03

### 추가
- **모임 리포트** (모임장 · 공동 모임장): 선을 나눈 사람 비율, 이 모임에서 다 그린 선, 함께 나눈 순간, 오간 응원, 나눈 순간의 마음 점수 분포(-5~+5)와 자주 쓴 감정 이름. 누가 무엇을 그렸는지는 없고 회고도 쓰지 않으며, 나눈 사람이 3명이 안 되면 마음 분포는 숨겨요.
- **나의 한 줄 달력**: ‘기록 모아보기 → 나의 한 줄’을 달력(남긴 날에 점) · 목록으로 봐요.
- **한 줄을 순간으로 옮기기**: 고른 그래프의 그 날짜쯤에 순간으로 놓여요 (제목 = 한 줄, 설명 = 그날의 질문).
- **자동 백업**: 서버가 하루 한 번 볼륨 안 `backups/auto-날짜.db` 를 남기고 최근 `BACKUP_KEEP`개(기본 7)만 둬요. 관리자 ‘쌓인 것’에 DB · 자동 백업 크기가 보여요.
- **하루 손질**: 끝난 로그인 지우기 · DB 통계 손보기(`PRAGMA optimize`) · WAL 합치기.

### 고침
- **큰 그래프 저장 실패**: 순간이 많고 회고를 길게 적으면 300KB(nginx 512KB) 한도에 걸려 저장되지 않을 수 있었어요. 2MB 로 늘렸어요 (순간 100개에 회고를 가득 적어도 들어가요).
- 오늘의 질문 입력칸: 따로 놀던 회색 칸과 갈색 버튼을 질문 아래 한 줄짜리 둥근 띠(안쪽 ‘남기기’)로 바꿨어요.

### 바뀜
- 오래 쓰면 느려지는 곳에 색인을 더했어요 (계정 지우기 · 모임 글 · 로그인 정리 · 응원 · 링크).
- Docker 로그는 10MB × 3개까지만 남겨요 (디스크가 차지 않게).
- 이용약관 · 개인정보 처리방침: 모임 리포트, 한 줄 → 순간 옮기기, 자동 백업 보관(기본 7일)을 적었어요.

## [0.17.0] - 2026-11-03

### 추가
- **같은 기간 다시 그려 보기**: 완성한 그래프의 결과 화면에서 누르면 같은 기간 · 선 색 · 제목으로 새 그래프를 시작하고, 처음 그린 선이 점선으로 겹쳐 보여요 (그리는 중에도, 결과 화면에서도).
- **오늘의 한 줄**: 첫 화면 ‘오늘의 질문’에 한 줄로 답을 남겨요 (날마다 하나, 나만 봐요). ‘기록 모아보기’의 ‘나의 한 줄’에서 모아 보고 지울 수 있어요. 로그인하지 않으면 이 기기에 남아요.
- **함께 그릴 주제**: 모임장 · 공동 모임장이 주제(80자)를 정하면 모임 화면과 모임 사람들의 첫 화면에 보이고, ‘이 주제로 그리기’로 바로 그 모임의 그래프를 시작해요.
- **신고**: 모임에서 남의 그래프를 ‘신고’할 수 있어요 (놀림 · 괴롭힘 / 개인정보 / 위험해 보여요 / 그 밖에). 운영자에게만 가고, 누가 신고했는지는 나눈 사람 · 모임장에게 알리지 않아요. 관리자 ‘신고함’에서 모임으로 가 보기 · 글 내리기 · 처리 완료를 해요.
- **한 권으로 저장 (PDF)**: 그래프 · 모든 순간 · 회고 · 지금의 나(열린 미래 편지 포함)를 책처럼 엮은 화면에서 인쇄 → ‘PDF로 저장’. 어두운 화면에서도 밝은 종이로 인쇄돼요.
- **웹에서 DB 복원**: 관리자 ‘백업 · 복원’에서 `.db` 파일 + 관리자 비밀번호 + 확인으로 되돌려요. 바꾸기 전 DB 를 서버에 최근 5개 남기고, 예전 버전 백업도 되며, 관리자 세션 · 접속 기록은 그대로예요. (nginx 는 이 주소만 200MB 까지 받아요)

### 바뀜
- **관리자 화면 전체 개편**: 왼쪽 메뉴(운영 / 사람과 기록 / 관리)와 본문, 화면마다 제목 · 설명, 사람 · 모임 · 나눈 그래프 찾기, 처리 안 한 신고 수 표시, 이름을 눌러 바로 열기, 주소(?tab=)로 화면 기억. 사람 자세히에 오늘의 한 줄.
- ‘인쇄하기’ 버튼은 ‘한 권으로 저장 (PDF)’로 바뀌었어요.
- 이용약관 · 개인정보 처리방침: 오늘의 한 줄 · 신고(보관 1년) · 함께 그릴 주제 · 다시 그린 그래프 연결 · 웹 복원 때의 파기 원칙을 적었어요.

- **로그인: 이름 + 생년월일 8자리** — 비밀번호를 받지 않습니다.
  - 가입: 이름 · 생년월일(예: 20120315) · 별명 / 로그인: 이름 · 생년월일
  - 입력한 생년월일을 ‘2012년 3월 15일’처럼 바로 읽어 보여주고, 없는 날짜 · 미래 날짜는 막습니다
  - 이름의 띄어쓰기 · 대소문자 차이는 같은 이름으로 봅니다
  - 서버에는 이름과 생년월일 원문을 저장하지 않고, 지문(HMAC)만 저장합니다
  - 같은 이름으로 생일을 계속 맞혀보면 15분 동안 막힙니다 (이름 기준 10회)
  - 교실 · 수련관처럼 여럿이 IP 하나를 쓰는 곳을 고려해 IP 기준 제한은 넉넉하게 조정
- 계정 지우기 확인도 비밀번호 대신 이름 + 생년월일

### 주의
- **v0.3.0 DB와 호환되지 않습니다** (v0.3.0 은 아이디 + 비밀번호). 옛 DB를 만나면 api 가
  안내 메시지를 남기고 멈춥니다. 미리보기 데이터라면 `docker compose down -v` 후 다시 시작하세요.
