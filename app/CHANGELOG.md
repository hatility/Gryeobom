# 그려봄 변경 내역

1.0.0 부터 정식 버전이에요. 버전마다 설치용 배포 묶음(`geuryeobom-v<버전>.zip`)은
깃허브 [Releases](https://github.com/hatility/Gryeobom/releases) 에서 받을 수 있고, 푼 폴더에서 `docker compose up -d --build` 로 실행해요.

버전은 `주.부.수` 세 자리로 매겨요.

- **예전 버전과 함께 쓸 수 없게 크게 바뀔 때** → 첫 숫자 (1.x.x → 2.0.0) — 올리기 전에 꼭 백업하고 안내를 읽어 주세요
- **기능 추가** → 가운데 숫자 (1.0.0 → 1.1.0)
- **버그 수정 · 작은 손질** → 마지막 숫자 (1.0.0 → 1.0.1)

`0.x.x` 는 정식 버전 전 미리보기 기록이에요.

## [1.1.1] - 2026-11-11

### 고침
- 결과 화면 · 공유 링크 · 예시 · 관리자의 순간 카드에서 시각 · 나이가 ‘12시…’ 처럼 잘리던 것 (모바일 ‘그때의 마음’ 순간 넘김 칸과 이름이 겹쳐 폭이 44px 로 묶여 있었어요).
- 관리자 모임 · 나눈 그래프 · 기관 · 사람 탭에서 띄어쓰기 없는 긴 이름이 있으면 화면 전체가 옆으로 밀리던 것 — 이제 표만 안에서 옆으로 넘겨요.
- 공유하기의 ‘나이 · 연도 · 달을 보여주기’ 를 그래프 기준에 맞게(‘시각을 보여주기’ 등).
- 아이폰에서 입력 칸을 누르면 화면이 확대되던 곳(기관 리포트 날짜 칸 등) — 모바일 입력 칸 글자를 모두 16px 로.
- 띄어쓰기 없는 긴 글(ㅋㅋㅋ… · 긴 영문)이 화면을 옆으로 밀던 것 — 한 권으로 · A4 한 장 · 오늘의 질문 · 제목들. 이미지 카드는 긴 제목을 글자를 줄여 맞추고 그래도 넘치면 … 로, 긴 문장은 글자 단위로 줄을 바꿔요.
- 참여 코드 표의 머리글 · 코드가 좁은 화면에서 꺾이던 것.
- 모바일에서 누르기 어렵던 작은 곳(오늘의 색 점 · 질문 넘김 막대)의 터치 영역을 넓혔어요.

### 바뀜
- 글자 수 표시를 맞췄어요 — 순간의 짧은 설명(300) · 미래의 나에게(500) · 여러 모임 소개(200) · 점검 안내(200) · 문의 답(2000)에 ‘0/300’ 처럼 보이고, 그때의 마음 · 지금의 나(1000)는 거의 찼을 때만 보여요. 질문 정하기 · 여러 모임 만들기에 글자 수 한도(질문 100자 · 예시 40자 · 할 일 60자 · 모임 이름 30자)를 적었어요.
- 모바일(아이폰): 나의 시간 ‘시간으로’ · ‘달로’ 의 날짜 · 시각 · 달 칸이 카드 밖으로 밀리던 것, 함께 나누기 모임 줄이 기관 꼬리표에 밀려 잘리던 것, 기관 리포트 표의 머리글 · 숫자가 한 글자씩 꺾이던 것(이제 표만 옆으로 넘겨 봐요), 기관 리포트 제목의 날짜가 중간에서 끊기던 것, 나의 한 줄의 ‘달력 · 목록’ 이 카드 밖으로 나가던 것.

## [1.1.0] - 2026-11-10

### 추가
- **개발 테스트용 배포 묶음 따로**: 빌드하면 정식 `배포/v1.1.0/` 과 함께 `배포/개발용/v1.1.0-dev/` 가 만들어져요. 개발용은 DB 볼륨(`geuryeobom-dev-data`) · 컨테이너 · 이미지 이름 · 기본 포트(8090)가 정식과 따로라, 같은 서버에 둘 다 띄워도 기록이 섞이지 않아요. 개발용에만 `DEV_SERVER=true` 가 들어가 화면 구석에 ‘개발 테스트 서버’ 표시가 뜨고 DB 초기화가 켜져요.
- **관리자 DB 초기화 (개발 테스트 서버에만)**: ‘관리 → 백업 · 복원’ 맨 아래. 정식 버전에는 화면에도 서버에도 없어요. 관리자 비밀번호를 한 번 더 넣고 ‘모두 지우기’ 를 그대로 적은 뒤 확인 창까지 거쳐야 실행돼요. 회원 · 그래프 · 모임 · 나눈 그래프 · 공유 링크 · 한 줄 · 응원 · 신고를 지우고(회원은 모두 로그아웃), 사이트 설정 · 공지 팝업 · 로그인 비밀값 · 관리자 접속 기록은 남겨요. 지우기 전 DB 는 서버 데이터 폴더에 `before-reset-…db` 로 남겨(최근 5개) 복원으로 되돌릴 수 있어요.
- **관리자 공지 팝업**: 관리자 화면 ‘운영 → 공지 팝업’ 에서 제목 · 내용을 적어 올리면, 사이트를 처음 여는 사람에게 한 번 떠요 (PC · 모바일 모두, 폰에서는 아래에서 올라와요). ‘확인’ 을 누르면 그 기기에서는 다시 뜨지 않고, 내용을 고쳐 다시 올리면 이미 본 사람에게도 다시 떠요. ‘내리기’ 로 꺼요. 관리자 화면에서는 뜨지 않아요.
- **모바일 · 태블릿 전용 화면 `/m`**: 휴대폰 · 태블릿으로 들어오면 자동으로 `/m` 으로 열려요. 기능 · 저장은 PC판과 같고, 화면 틀이 앱처럼 바뀌어요.
  - **아래 탭바** 처음 · 기록 · 그리기 · 함께 · 나 — 가운데 ‘그리기’는 떠 있는 동그란 버튼
  - **위 앱 바** 뒤로 가기 버튼, 내리면 화면 제목이 작게 떠올라요
  - **모바일 첫 화면** 인사 · 새 그래프 그리기 · 이어 그리기 · 오늘의 질문 · 내 그래프를 옆으로 넘겨 보기 · 모임 주제
  - **‘나’ 화면** 계정 · 화면 밝기 · 글자 크기 · 약관 · 오픈소스 · PC 화면으로 보기 · 로그아웃을 한곳에
  - **아래에서 올라오는 시트** 공유 · 신고 · 저장 같은 팝업
  - **기록 목록** 작은 그래프를 왼쪽에 둔 줄 모양
  - 누르면 살짝 눌리는 느낌, 화면이 바뀔 때 부드럽게 떠오름, 손가락 크기 버튼(44px), 입력할 때 확대되지 않는 입력칸, 노치 · 홈 막대 자리 비움
  - **태블릿** 아래 탭바 대신 왼쪽 세로 메뉴, 기록은 2열 (가로로 넓으면 3열)
- **모바일 · 태블릿의 그래프는 누르기만**: 손가락으로 점을 끌어 옮기기는 잘 맞지 않아 껐어요. 빈 곳을 누르면 순간이 더해지고, 점을 누르면 한 질문씩 넘기는 창에서 언제 · 마음의 높이를 골라요. 안내 문구도 그에 맞게 바꿨고, 점 위에서 시작해도 화면이 위아래로 잘 넘어가요. (PC 는 지금처럼 끌어서 옮겨요.)
- **화면 바꾸기**: ‘나 → PC 화면으로 보기’ · PC 바닥글 ‘모바일 화면으로 보기’. 고른 화면은 그 기기에서 기억해요.
- 초대 · 공유 링크는 그대로 쓰면 되고, 여는 기기에 맞는 화면으로 열려요. 관리자 화면은 PC판으로 열려요.

### 더한 기능 (1.1.0 정식 — 개발 테스트 서버에서 써 본 것들. ‘만 14세 미만 보호자 동의’ 만 아직 관리자 ‘실험 기능 스위치’ 로 켜요)
- **만 14세 미만 보호자 동의**: 가입 · 초대 링크 가입에서 생년월일로 만 나이를 보고, 14세 미만이면 보호자(부모님 · 보호자 · 기관 담당 선생님) · 보호자 연락처(휴대폰 · 이메일) · ‘함께 읽고 동의했어요’ 를 받아야 가입돼요. 가입하면 **보호자 확인 링크**(`/guardian/…`)가 기록 모아보기 · 처음 화면에 뜨고, ‘링크 보내기 · 복사’ 로 보호자에게 보내요. 보호자가 열어 내용을 읽고 ‘동의해요’ 를 누르면 확인이 끝나고 알림이 사라져요. 관리자 ‘사람 자세히’ 에 확인됨 / 기다리는 중이 보여요.
- **내 기록 모두 내려받기**: 기록 모아보기 아래 · 모바일 ‘나’ 에서 JSON 파일 하나로 (그래프 · 회고 · 한 줄 · 모임 · 나눈 그래프 · 공유 링크).
- **여러 모임 한 번에 만들기 (기관용)**: 함께 나누기에서 한 줄에 하나씩 30개까지. 참여 코드 · 초대 링크 표를 인쇄 · PDF 하거나 CSV 로 받아요. 만든 사람이 모든 모임의 모임장이에요.
- **모임 리포트 인쇄 · PDF**: 모임 리포트만 깔끔하게 한 장으로 (모임 이름 · 날짜 · 개인이 드러나지 않는 통계).
- **관리자 기간별 통계**: ‘한눈에’ 아래. 최근 30일 · 이번 달 · 지난달 · 올해나 날짜를 골라 새 가입 · 그래프 · 모임 · 나눔 · 응원 · 오늘의 한 줄을 날마다 보고 CSV 로 받아요.
- **홈 화면에 앱처럼 설치**: 휴대폰 브라우저의 ‘홈 화면에 추가’ 로 그려봄 아이콘이 생기고 주소창 없이 열려요.
- **이미지 카드 배경**: 이미지로 저장할 때 종이 · 노을 · 풀잎 · 하늘 중에서 골라요.
- **그때의 마음 질문 묶음**: 3단계에서 기본 · 진로 · 관계 · 학교생활 질문으로 바꿔 볼 수 있어요 (적은 글은 그대로).
- **모임 소식**: 모임장 · 공동 모임장이 모임 사람들에게 소식(300자까지)을 올려요. 모임 화면과 회원의 첫 화면에 보이고, 아직 안 읽었으면 ‘새 소식’ 표시가 붙어요.
- **종이 활동지 인쇄** (`/worksheet`): 빈 그래프 칸 · 순간 표 · 그때의 마음 질문(질문 묶음 고르기) · 지금의 나 질문을 A4 로. 기기 없이 교실에서 먼저 그려 보고 옮겨 적어요. ‘나’ 화면 · 여러 모임 만들기 옆에서 열어요.
- **관리자 활동 기록**: ‘관리 → 관리자 활동 기록’. 한 사람 · 모임의 기록 열람, 지우기 · 내리기, 설정 · 공지 저장, 백업 · 복원 · 초기화를 시각 · IP(별칭) · 대상 이름과 함께 남겨요 (목록 보기는 남기지 않음, 최근 5000건, CSV).
- **모임 활동 일정**: 모임장 · 공동 모임장이 날짜 · 활동 이름을 더하고 지워요 (다가오는 것 20개까지). 모임 화면 ‘다가오는 활동’ 과 회원의 첫 화면(‘다음 활동 · 11월 7일 (토) · …’)에 보여요.
- **기관 담당자**: 관리자 ‘사람과 기록 → 기관’ 에서 기관을 만들고 모임 참여 코드로 모임을 묶고 담당자 계정을 정해요. 담당자는 `/org`(기관 리포트, 기록 모아보기 위 버튼 · 모바일 ‘나’)에서 묶인 모임의 리포트만 모아 보고 인쇄해요. 개인 기록 · 별명은 볼 수 없어요.
- **한 해 돌아보기 다듬기**: 올해 모임에서 받은 응원 수, 그 해의 마음 단어가 화면과 ‘한 장으로 저장하기’ 카드에 함께 들어가요.
- **휴면 계정 정리**: 관리자 ‘관리 → 휴면 계정’. 마지막으로 다녀간 지 6 · 12 · 24개월이 넘은 계정을 골라 정리해요 (정리하는 순간에도 다시 확인해 그 사이 다녀간 사람은 남김, 관리자 활동 기록에 남음).
- **기관 리포트 기간**: `/org` 에서 이번 달 · 지난달 · 이번 분기 · 올해나 날짜를 골라, 그 기간의 새로 들어온 사람 · 모임에서 그린 그래프 · 나눈 글 · 응원 · 활동 · 참여(연인원)를 모임별로 봐요.
- **모임 출석**: 활동 날부터 7일 안에 ‘참여했어요’ 를 눌러 남기고 풀어요. 누가 참여했는지는 본인만, 다른 사람에게는 인원 수만 보여요. 지난 7일 활동은 ‘지난 활동’ 으로 보여요.
- **모임 복제**: 모임 화면 아래 ‘이 모임 설정으로 새 모임 만들기’ — 이름만 정하면 소개 · 함께 그릴 주제 · 함께 그릴 시간을 그대로 가져와요 (사람 · 글은 빼고).
- **‘지금의 나’ 단어 카드**: 4단계 ‘지금의 나를 가장 잘 표현하는 단어’ 아래 16개 카드를 눌러 고를 수 있어요.
- **최근 오류**: 관리자 ‘관리 → 최근 오류’ 에 서버 오류(시각 · 주소 · 내용)를 최근 500건까지. 누가 보냈는지 · 적은 내용은 남기지 않아요.
- **나의 마음 단어**: 순간마다 고른 감정과 ‘지금의 나’ 단어를 모아 자주 쓴 것을 크게 — 기록 모아보기 · 한 해 돌아보기에서 (나만 보기, 서버에 따로 모으지 않음).
- **5차 실험 (16가지)**
  - **인생 구간 띠**: 그리기 1단계 ‘인생 구간 띠’ 에서 ‘초등학교 7살 ~ 13살’ 처럼 8개까지 — 그래프 시간 눈금 아래 색 띠로 깔려요 (결과 · 한 권 · A4 한 장에도).
  - **나만의 질문**: 3단계 질문 묶음 아래에 내 질문 3개까지 더하면, 순간마다 기본 질문과 함께 나와요. 빼면 그 질문의 답도 함께 빠져요.
  - **전환점 ★**: 순간 창 맨 아래 ‘내 인생의 전환점이에요’ 를 켜면 그래프 점이 금색 별로, 목록 · 결과에 ★.
  - **A4 한 장 인쇄**: 결과 화면 ‘A4 한 장 인쇄’ (`/graph/…/sheet`) — 그래프 · 순간 목록 · 지금의 나 한 줄 (회고 없이).
  - **모임 참여 QR**: 모임 참여 코드 아래 ‘QR 로 크게’ — 휴대폰 카메라로 찍으면 초대 링크가 열려요. 인쇄도 돼요.
  - **큰 화면 진행 모드**: ‘큰 화면 진행 모드’ (`/groups/…/present`) — 주제 · 진행 단계 · 타이머(3 · 5 · 10 · 15분) · QR · 함께하는 인원 · 오늘 참여 인원, 전체 화면.

- **모임장이 질문 정하기**: 모임 화면 ‘모임 꾸리기 → 질문 정하기’. 이 모임에서 그릴 때 나오는 ‘기억에 남는 순간’ 예시, ‘그때의 마음’ · ‘지금의 나’ 질문 5개씩을 고쳐 쓰거나 ‘묻지 않기’ 로 빼요. 그리기를 시작한 그래프에 그때의 질문이 함께 담겨, 나중에 모임이 바꿔도 그 그래프는 그대로예요. 모임을 복제하면 질문도 따라가요.
- **큰 화면 ‘오늘 할 일’**: 같은 카드에서 큰 화면 진행의 할 일을 적어요 (진행안을 골라 들어오면 진행안이 먼저). ‘(3분)’ 처럼 적으면 타이머가 그 시간으로 맞춰져요.
- **기관 등록 안내**: 기관을 등록하기 전에 ‘실제 기관 담당자예요 · 장난 등록은 지워질 수 있어요 · 담당자는 통계만 봐요’ 세 가지를 확인해야 해요. 친구 · 동아리라면 모임 만들기로 안내하고, 만 14세 미만으로 가입한 계정은 기관을 등록할 수 없어요. 내가 맡은 기관 화면 오른쪽에 ‘기관은 이렇게 써요’ 안내, 기관이 없는 회원의 첫 화면에 ‘기관 등록하기 ›’ 한 줄.

### 바뀜
- 정식이 된 기능의 ‘실험’ 표시를 뺐어요 (관리자 메뉴 · 함께 나누기 · 기간별 통계 등). 남은 실험 기능은 보호자 동의 하나예요.
- 사용 설명서를 1.1.0 에 맞췄어요 — 모바일 화면, 달로 · 시간으로, 건너뛰기, 문의하기, 모임 질문 정하기 · 큰 화면 진행 · 도우미, 기관으로 쓰기, 관리자 메뉴 13개, 한 시간마다 자동 백업, 새 버전으로 올릴 때 되돌리기 주의.
- **실험 기능을 정식으로**: 나의 선 더하기 · 모임 더하기 · 기관 · 내 기록 · 문의 · 약관 · 운영 도구 다섯 묶음은 정식 서버에서도 늘 켜져요 (관리자 스위치에 ‘정식’ 표시, 끌 수 없음). ‘만 14세 미만 보호자 동의’ 만 스위치로 남겼어요. 이용약관 · 개인정보 처리방침도 ‘시험 중’ 표시를 떼고, 보호자 조항은 그 스위치를 켰을 때만 보여요.
- **그리기 3 · 4단계 PC**: 접힌 카드(질문 바꾸기 · 순간 · 미래의 나에게)를 한 줄 높이로, 순간마다 반복되던 ‘건너뛰어도 괜찮아요’ 를 뺐어요.
- **‘+ 순간 적기’ 자리**: 새 순간을 가장 넓게 빈 곳에 놓아, 여러 개 더해도 한 점에 겹치지 않아요.
- **시간으로 입력**: 날짜 하나 + 시작 · 끝 시각, 며칠이면 ‘다른 날에 끝나요’. 눈금은 폭에 맞춰 겹치지 않게.
- **함께 나누기 크기**: 나누기 약속 글자를 키우고, 들어가기 · 새 모임 카드 높이를 맞췄어요.
- **나의 시간 ‘달로’**: ‘최근 12개월’ 과 ‘올해’ 를 하나로 — 시작 달과 끝 달을 골라요 (처음엔 최근 12개월, 36개월까지). 예전 그래프 · 모임 설정은 그대로 열려요.
- **그리기 1단계 PC**: 왼쪽 미리보기는 내용만큼만 두고 그래프를 카드 폭에 꽉 채워, 스크롤해도 따라와요 (‘시작하기 전에’ 는 한 줄로). 오른쪽은 번호 머리를 빼고 질문만, ‘누가 볼까요’ 는 두 칸 고르기, 인생 구간 띠는 접어 둬요.
- **그리기 2단계**: 순간 더하기를 그래프 위 ‘+ 순간 적기’ 하나로. 예시는 순간이 없을 때만 ‘막막하면 예시’ 로 접혀 있고, 누르면 같은 창이 그 제목으로 열려요.
- **그리기 3 · 4단계 건너뛰기**: 3단계는 질문 묶음을 ‘⚙ 질문 바꾸기’ 한 줄로 접고, 순간은 하나씩 펼치며 질문 2개만 먼저(‘질문 더 보기’), 순간마다 ‘이 순간 건너뛰기’, 위에 ‘건너뛰고 지금의 나로 ›’. 4단계는 단어 · 한 문장만 먼저(‘+ 더 적어 보기’), ‘적지 않고 완성하기 ›’, 미래의 나에게는 접어 둬요.
- **응원 보내기 줄**: 모임에 나눈 그래프 바로 아래에 늘 보이고, 누르면 색이 바뀌며 ✓ 가 붙어요. 받은 응원 수는 지금처럼 그린 사람에게만.
- **함께 나누기 정리**: 기관별 묶음 대신 내 모임을 한 줄씩(기관은 작은 꼬리표). 기관이 없는 사람에게는 맨 아래 ‘기관 등록하기 ›’.
- **기관 탭**: 기관을 맡은 계정은 맨 위 메뉴에 ‘기관’. 첫 화면의 기관 카드는 ‘내가 맡은 기관 N곳 ›’ 한 줄로, 모임 소식은 두 줄까지만.
- **기관 화면**: 관리자 → 기관은 기관당 한 줄 표(초대 링크는 ‘고치기’ 안), ‘내가 맡은 기관’ 은 목록과 등록 칸 폭을 맞췄어요.
- **결과 화면 버튼**: 공유하기 하나를 크게, 나머지는 ‘저장 · 인쇄’ · ‘고치기’ 두 묶음으로. A4 한 장 · 한 권의 위 줄은 왼쪽 ‘← 그래프로’, 오른쪽 인쇄, 설명은 아래 줄.
- **관리자 활동 기록을 뺐어요**: 활동 기록 탭 · 기록 남기기를 없애고, 메뉴 이름은 ‘접속 · 차단’ 으로. 관리자 로그인 기록은 그대로예요.
- **모바일 · 태블릿은 읽기 편하게, 그래도 그려봄답게**: 장식용 영어 머리글(MY LINE, SO FAR 같은)은 빼고, 그 자리에 은은한 꾸밈을 — 계절 점이 붙은 인사, 노을빛 ‘새 그래프 그리기’ 카드와 선 한 줄, 종이처럼 옅은 카드 그림자, 구역 제목 앞 작은 선, 내 그래프마다 선 색 점, 고른 탭 뒤 둥근 띠, 화면이 바뀔 때 살짝 나타나기 (움직임 줄이기를 켠 기기는 그대로). 아래 탭바의 ‘그리기’ 는 다른 탭과 같은 모양이에요.
- PC 화면을 좁은 창으로 볼 때 나오던 아래 탭바를 뺐어요 (탭바는 모바일 화면 `/m` 에만). 메뉴는 머리 아래 한 줄로 보여요.

### 고침
- 나의 시간에서 기준(나이로 · 연도로 · 달로 · 시간으로)을 잘못 누르면, 이미 적은 순간들이 새 기간 안으로 조용히 옮겨져 저장되던 것 — 순간이 있으면 바꾸기 전에 한 번 물어봐요.
- 첫 기관을 등록하거나 마지막 기관을 지운 뒤, 맨 위 ‘기관’ 메뉴와 첫 화면의 기관 줄이 새로 고칠 때까지 바뀌지 않던 것.
- 큰 화면 진행 위에 관리자 알림(‘새 문의’)이 겹쳐 뜨던 것.
- 마지막 점검: 결과 화면 ‘저장 · 인쇄’ · ‘고치기’ 줄 맞춤, 모임 화면 글 버튼 · ‘질문 정하기’ 들여쓰기, 나눈 그래프 카드 겹친 여백, 함께 나누기 두 버튼 폭, 이미지로 저장하기 체크 칸, 첫 화면 카드 간격.
- 모든 순간의 마음이 0 이면 순간끼리 잇는 선이 보이지 않던 것.
- 큰 화면 진행에서 긴 주제(80자)가 한 줄로 화면 밖까지 넘치던 것 — 줄을 바꾸고 길이에 맞춰 글자를 줄여 3줄까지. ‘오늘 할 일’ 카드의 큰 빈칸, 오른쪽 QR 카드가 화면 밖으로 넘치던 것.
- 이미지로 저장하기 창이 위로 붙어 있던 것 — 모든 창이 화면 가운데에, 길면 창 안에서 스크롤.
- 모바일 결과 화면에서 ‘공유하기’ 버튼이 카드 밖으로 넘치던 것.
- ‘달로’ 그래프의 이미지 카드 제목이 기간과 맞지 않던 것 (1월부터면 ‘N년, 나의 한 해’, 열두 달이면 ‘나의 열두 달’, 그 밖은 ‘나의 N개월’).
- 관리자 화면 탭 제목에 ‘[개발]’ 이 두 번 붙던 것. 모바일 개발 서버에서 ‘개발 테스트 서버’ 표시가 위 제목과 겹치던 것(모바일은 맨 위 줄무늬 띠만).
- 완성 버튼 직후 늦게 온 자동 저장이 ‘완성’ 을 ‘그리는 중’ 으로 덮어쓰던 것. ‘지금의 나’ 칸이 일부 없는 예전 기록을 열면 4단계가 깨지던 것.
- 관리자 로그아웃 뒤에도 신고 · 문의 알림 숫자 · 탭 제목 (n) 이 남던 것, 화면을 빨리 떠나면 관리자 알림 확인이 멈추지 않던 것.
- 모임 화면이 인터넷이 잠깐 끊겨도 ‘모임을 찾을 수 없어요’ 로 바뀌던 것, 기관 목록을 못 불러오면 ‘불러오는 중’ 에서 멈추던 것, 로그인한 사람에게도 ‘이 기기에만 저장돼요’ 라던 결과 화면 안내.
- PC 맨 위 메뉴 가운데에 ‘개발 테스트 서버’ 표시가 겹치던 것, 모바일 한 해 돌아보기의 마음 색 지도가 오른쪽으로 넘치던 것, 모임 ‘소식’ · ‘주제’ 빈 카드 모양이 달랐던 것, 기록이 하나뿐일 때 오른쪽이 비던 것.
